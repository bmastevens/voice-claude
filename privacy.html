Privacy policy

Voice Claude. Last updated 18 November 2026.

Voice Claude is a personal app with a single user, its owner. This policy explains what it does with Google user data and anything else it handles.

Data it accesses

  • Gmail (read only): message headers and content, read on request so they can be summarised aloud.
  • Gmail (compose): used only to create drafts in the owner's account. Voice Claude never sends, deletes or modifies existing messages.
  • Google Calendar (read only): event details, read on request.
  • Voice: audio spoken to the app, converted to text so it can be answered.

How it is used

Data is used only to answer the owner's requests in the moment: reading out mail or diary entries and drafting replies. It is not used for advertising, not sold, not used to build profiles, and not shared with anyone except the service providers below, which process it only to provide the feature.

Where it is processed

  • Google Cloud runs the app on Cloud Run and Cloud SQL in London (europe-west2). Speech is converted to and from text by Google Cloud speech services in the EU.
  • Anthropic provides the Claude model through its API. The text of a request, and any mail or calendar content needed to answer it, is sent to the Claude API to generate the reply. Anthropic does not use API data to train its models.

Storage and retention

  • Mail and calendar content is fetched when needed and is not kept after the reply is given.
  • Transcripts and message bodies are never written to logs. Logs hold metadata only, such as which tool ran, the policy decision and timing.
  • An audit log of actions (metadata only) is kept for 90 days.
  • Drafts the owner prepares for other mailboxes are encrypted at rest, deleted as soon as they are delivered, and purged after 7 days if never delivered.
  • The Google sign-in token is stored encrypted in Google Cloud Secret Manager.

Security

Access is limited to the owner's enrolled phone and Google account. Data is encrypted in transit and at rest. Actions that cannot be undone are blocked in code while driving.

Your control

Access can be withdrawn at any time from Google Account permissions. Withdrawing it stops all further access straight away, because the stored token no longer works.

Google API Services User Data Policy

Voice Claude's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be raised as an issue on this site's GitHub repository.
